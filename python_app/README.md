# Cybercrime Reporting and Digital Evidence Management System

## Project Overview

This project is a desktop application developed using Python, Tkinter, and SQLite to support cybercrime complaint registration, tracking, and management.

A Power BI dashboard is included to visualize cybercrime complaint data and provide insights into complaint trends and status.

## Technologies Used

* Python
* Tkinter
* SQLite
* Power BI
* DAX (if used in the dashboard)

## Python Application Features

* User registration and login
* Cybercrime complaint submission
* Complaint tracking
* Complaint status management
* Admin complaint management
* Digital evidence management (if implemented)

## Power BI Dashboard

The dashboard is designed to summarize and visualize available cybercrime complaint data. Its actual KPIs, charts, and filters are documented based on the implemented dashboard.

## Repository Structure

* `python_app/` — Python application source files
* `powerbi_dashboard/` — Power BI dashboard and screenshots
* `docs/` — Optional project documentation

## How to Run the Python Application

1. Install Python.

2. Download or clone this repository.

3. Open the `python_app` folder in VS Code.

4. Run the application's main Python file, for example:

   `python cybercrime.py`

5. Follow the application's on-screen instructions.

The actual main filename and database initialization steps may vary depending on the project implementation.

## Data Privacy

The working SQLite database and any real personal or complaint information are not included in this repository. Use synthetic or anonymized data for demonstrations.

## Project Purpose

The project demonstrates desktop application development, database integration, complaint management, and business intelligence reporting.
